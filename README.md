# Wayo: Naija Hide & Seek

A Nigerian 3D multiplayer prop hunt set in Computer Village, Ikeja. Traders hide by turning into goods on the street; the Task Force has four minutes to find them.

- Phones first (landscape), works on desktop too.
- Online rooms: create a room, share the 5-letter code (or the WhatsApp link), the host starts the match.
- Static site: `index.html` plus the `props/`, `chars/`, `tex/` and `audio/` folders. No build step.

Live at https://playwayo.netlify.app. Deployed on Netlify straight from this repository (publish directory: the repository root).

Credits for 3D models, textures and map data are listed in the game under **Credits**.
